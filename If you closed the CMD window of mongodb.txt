If you closed the CMD window that was running MongoDB on port 27018, then MongoDB is no longer running, so your Python code cannot connect.

Step 1: Open Command Prompt

Press:

Windows + R

Type:

cmd

Press Enter.

Step 2: Start MongoDB Again

Use the same command you used earlier.

For example:

"C:\Program Files\MongoDB\Server\8.2\bin\mongod.exe" --port 27018 --dbpath C:\MongoDB_Crowd\data

Keep this CMD window open.

You should see something similar to:

Waiting for connections
port: 27018

Do not close this window.

Step 3: Verify Connection

Open MongoDB Compass.

Connection string:

mongodb://localhost:27018

Click:

Connect

You should see:

crowd_monitoring
├── crowd_counts
└── crowd_summary
Step 4: Run Your Application

Open a new terminal:

cd "C:\Users\ratna\python_pro\QUEUE MOINTORING\videomanagement"

python main.py
Step 5: Check MongoDB

After a few seconds, refresh:

crowd_counts

You should see documents being added every second.

If You Don't Remember the mongod Path

Open CMD and run:

where mongod

If it returns something like:

C:\Program Files\MongoDB\Server\8.0\bin\mongod.exe

then use that path in Step 2.

Better Long-Term Solution

Right now, every time you reboot Windows or close the MongoDB CMD window, you must restart MongoDB manually.

A better setup is to run MongoDB as a Windows Service, so it starts automatically when Windows starts.
